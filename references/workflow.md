# 中重档完整工作流(从主文件下沉,轻档不需要看这页)

主文件的四条原则 + 速查够轻档用。中档(手记/周报)、重档(硬文/对外文档)要走下面这套完整流程。**这里的每一条都是从原版主文件原样搬下来的死线/判据,不是新增,也一条没减。**

---

## 五段主流程(中档、重档必走;轻档并进心里做)

### 第一段:事实闸门(改前锁账本)

改任何一个字之前,先把**关系账本**列出来。账本 8 项:

- **数字**:所有数字、单位、比例、时间、人名。
- **命令 / 代码 / 术语 / 专有名词**:凡是引号、代码块、`code` 包住的、以及首字母大写的英文术语,视为不可修改的**受保护跨度**(protected span,详见 `protected-spans.md`)。
- **谓词方向**:「A 导致 B」不能变成「B 导致 A」;「A 大于 B」不能变成「A 小于 B」;「A 属于 B」不能变成「B 属于 A」。
- **效果类型**:上升 / 下降 / 不变 / 存在 / 消失,不许翻转。
- **关系类型**:因果 / 并列 / 转折 / 递进 / 让步,不许换。
- **模态**:「可能」「一定」「大概率」不许升级或降级。
- **硬机制描述**:「Q-K 点积加权求和」「反向传播」「AST 遍历」这类精确算法/机制描述,不许替换成比喻或简化说法。想加比喻,叠在机制后面(先给准确机制,再补比喻),不许替换。
- **论文级证据**:「Kenneth Li 等在 Othello-GPT 里发现……(ICLR 2023)」这类可追溯的实验描述,作者/机构/年份/结论不许被简化成「有研究发现」「科学家表示」。

账本用几行 checklist 记住(或写到暂存区)。改完最后一步逐条对回去。**任何一条对不上,该句作废,回去重改**。

### 第二段:症状库四层扫描 + 回译兜底

按 `symptom-dictionary.md` 逐层扫描,标注命中项:标点级 / 句式级 / 词汇级 / 结构级。

标注完密度先自检:**某段命中 > 5 处 → 该段整体不对,单点改不救,直接考虑重写(重档)或整段列删除清单(中档)**。

**回译测试兜底**:任何一句拿不准是不是 AI 味,默读一遍翻回英文。英文一次成型 → AI 味;英文别扭需要意译 → 中文。**注意**:回译是给人用的疑难句判定器,不逐句逐段跑,不当自动化流程的门槛(极简白话/技术议论中文本身回译也顺,别一刀切)。

### 第三段:力度 × Scope 动刀

按上一段扫出来的密度和当前档位的默认力度/scope 配置下刀:

- **五刀减法**(见 `symptom-dictionary.md`「减法五刀」节):名词化→动词;后缀病→删或换;破折号→逗号/句号;前者后者→重复主语;长复合句→短句串珠。
- **四问加法**(见主文件「加中文味」四问 / `chinese-four-principles.md`):动词扛住了没?有具体没?句子该补气口/拆开没?段末多话删了没?

**Scope = bounded 时的硬约束**:
- 不擅自删整句。发现某句该删,记进**「建议删除清单」**,主流程末尾统一交作者定夺。
- 结构级重排(合并两段、拆分一段、调整章节顺序)必须先问,不许直接做。

**Scope = structural 时**:结构级重排可自主做,但每次都要在 report 里说明「原来是……,改后是……,因为……」。

### 第四段:回读(重档强制;中档抽查)

改完不许直接交。分遍念,**三遍分开做,不许合并**(合并的结果就是「越改越顺、越顺越不像原稿」,最终跑题):

- **Pass 1 · 只对事实**:拿第一段的关系账本一条条对回去。**只查、不改结构、不查行文**。任何一条对不上,回第三段重改该处。
- **Pass 2 · 只查残留 AI 味**:整篇再念一遍,只找漏网的四层症状。**发现问题只做局部替换,不许借机重写全文**——这步是收尾,不是再来一遍。
- **Pass 3 · 节奏终审**(重档强制;中档只跑憋气句):按 `rhythm-check.md` 四个字面指标(憋气句/句长单调/软尾串/调子单一)粗筛标红,逐处念一遍定夺。**只补气口、只微调句式,不推向口语化,不拆好长句。** 误报(URL、排比、专名列表)放过。

### 第五段:主线反思(软性,不强制约束)

改完 skill 自己回读全文,回答三问,跟着 report 一起给:

1. **主线是什么?** 一句话讲清整篇核心主张。讲不出来 → 主线已散,需作者定夺是否重来。
2. **每一节还在为它服务吗?** 逐节问「删掉这节,主线还立得住吗?立得住 → 这节是废段,标出来。」
3. **比改之前更清楚,还是更散?** 只跟改前比,不跟理想比。改后更散(常见于补丁摞补丁)→ 标出偏离点交作者,**不擅自回滚**。

**不当硬约束**——有时候作者就是想改结构、想让主线松一些,不能限死。这步只做提醒。

## Report 模板(中档、重档必给;轻档不给)

```
【改后正文】
<改完的中文>

【事实核对】
- 关系账本 N 条,全部对齐 ✓
(如有对不上,说明该处未改动或回退原状)

【本次动刀】
- 减法五刀命中:XX 处(简要 1 行)
- 加法四问补充:XX 处(简要 1 行)

【建议删除清单】(bounded scope 独有)
- 第 N 段第 M 句「……」建议删,理由:段末打钉/同义反复/凑三/……

【主线反思】
- 主线一句话:……
- 有无偏离:无 / 有(说明哪一节偏了)
- 比改前:更清楚 / 更散(简答)
```

轻档只给改后正文,不给这套 report。
